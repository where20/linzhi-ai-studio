## 1. 站点架构解析

```
dfxg.my-place.us/?i=2          ← 外壳壳页（含 i=N 计数跳转 / "新窗口打开"引导 / sentinel 反爬蜜罐）
  └─ iframe: https://agnes-ai-studio-02306.app.workbuddy.host/   ← 真正的应用（WorkBuddy 云托管）
       ├─ 单文件 index.html（3.16MB，CSS/JS 全内联）
       ├─ /hejian/hejian.js?v=373（合剪模块，独立拆分）
       ├─ /poseatlas/*（形衣图鉴子站，多页面 + 独立 assets）
       ├─ /jizura/（JIZURA 歌词视频工具，2.4MB 自包含单页）
       ├─ /codevideo/scenes/studio.html（合剪工作台）
       └─ /api/*（后端 API，406 个端点）
```

**关键结论**：外壳与本体分离，复刻只需对准 `agnes-ai-studio-02306.app.workbuddy.host` 本体；
本项目 server.js 的代理 target 本来就指向它，直接换前端资源即完成升级。

## 7. 风险与余留

1. **会员墙**：生图/视频等核心能力需原站账号+会员卡，本地代理只透传，无法绕过（也不应绕过）。
2. **sentinel 蜜罐**：原站有 `/api/sentinel/trap` 反爬蜜罐，代理会一并透传；不要主动请求它。
3. **单文件膨胀**：原站已把合剪拆出独立 JS（"codevideo 1万+ 行教训"），后续更新时注意沿用拆分结构。
4. **版本跟进**：poseatlas 资源带 `?v=1.8.394` 版本号，下次升级可从该参数直接读最新版本。
5. Google Fonts 走外网 CDN，离线环境会回退系统字体（不影响功能）。

## 8. V2 追加：本地完整版（免登录 · 非套壳）

用户需求：本地项目不要登录墙，要完整网站功能。已实现 `local-api.js` 本地适配层（server.js 中先于代理注册）：

| 层 | 端点 | 实现 |
|---|---|---|
| 门禁 | /api/member/gate·whoami·logout, /api/auth/ciam/status, /api/account/* | 本地放行桩，bootGate 直接 unlocked |
| 配置 | GET/POST /api/config, /api/config/test-key | config.json `ai` 字段落盘（Key 掩码回显） |
| 对话 | POST /api/ai/chat（sync + async job）, GET /api/ai/chat/status | Agnes `/v1/chat/completions` 流式，reasoning 与正文分离 |
| 生图 | /api/image/generate, /api/image/img2img | Agnes `/v1/images/generations`，产物落盘 output/pictures |
| 视频 | /api/video/generate + /api/video/status/:id | Agnes `/v1/videos` 任务制，完成后拉回 output/videos |
| 热点 | /api/news/hot, /api/news/trending | RSS 聚合（36氪/IT之家/少数派/极客公园/量子位），30min 缓存 |
| 作品墙 | /api/gallery/* | output/gallery.json 本地存储 |
| 上传 | /api/upload/image | multer 落盘 output/uploads |

**实测结果（2026-11-04）**：
- 登录墙消失，顶栏「本地用户」，20 版块全部直通 ✅
- UI 端到端对话成功（agnes-2.5-flash · 3s 回复，无思维链混入）✅
- UI 端到端生图成功（1024×1024，12s，本地 /output/pictures/）✅
- 新闻/全网热点真实数据渲染 ✅（修复 ts 原始毫秒显示 → 格式化为 MM-DD HH:mm）
- 上传接口 ✅

**踩坑记录**：
- `app.use('/api', ...)` 内 `req.path` 不含挂载前缀 → JSON 解析匹配要用 `req.originalUrl`
- 全局 `express.json()` 会吃掉请求流导致 http-proxy 转发失败 → 只对本地 POST 路径挂 json 解析
- agnes-client `chatStream` 把 `reasoning_content` 混进 onDelta → 本地副本加 `onReasoning` 分流
- `loadConfig` 合并时保留 `...fileConfig` 展开，否则 ai 字段被丢弃
